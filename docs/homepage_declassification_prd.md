# HopEnglish 首页去分类产品需求

**文档类型：** 产品需求文档  
**适用产品：** HopEnglish  
**核心用户：** 2–5 岁儿童  
**需求主题：** 将分类从儿童首页的必经选择，调整为自由探索入口

---

## 一、需求背景

HopEnglish 面向 2–5 岁儿童，核心定位是通过稳定、即时的“点击—图片—声音—反馈”帮助孩子建立英语声音与意义的直接联系。产品不是要求儿童阅读、理解说明或规划学习，而是让孩子点一下就能进入学习闭环。

当前首页将 Animals、Foods、Vehicles 等分类作为主要入口。孩子必须先选择分类，才能看到并学习单词。随着分类数量和课程能力增加，这种结构逐渐暴露出以下问题。

### 1. 分类选择不是低龄儿童必须完成的学习任务

2–5 岁儿童，尤其是 2–3 岁儿童：

- 无法依赖英文分类名称完成选择；
- 容易理解 Animals、Foods 等具体主题，但较难理解 Nature、Places、Jobs 等抽象分类；
- 可能只是根据某张图是否吸引自己来点击，而不是理解所选主题；
- 面对多个平级入口时，可能出现犹豫、重复点按或停留在首页；
- 真正想做的是“马上看到、听到并玩一个东西”，而不是先理解内容架构。

首页要求孩子先选分类，相当于在学习闭环之前增加了一项不必要的认知任务。

### 2. 分类首页强化了“图片词典”而不是“启蒙学习工具”的感受

分类网格更适合表达“这里有很多内容供你查找”，天然接近资源目录或图片词典。

但 HopEnglish 已经具备：

- 每课学习 5/6/8 个词；
- 单词学习与听音选图闭环；
- 学习记录和复习逻辑；
- 完成后的庆祝与继续学习。

产品已经能够主动组织一次短时学习体验。如果首页仍以内容分类为中心，产品入口表达的是“浏览什么”，实际功能表达的却是“完成一节学习”，两者不一致。

### 3. 儿童自主选择容易造成长期内容偏科

低龄儿童具有稳定而强烈的兴趣偏好，可能长期只点击动物、车辆等喜欢的主题。这符合自由探索行为，但不适合作为默认学习安排，可能导致：

- 少数喜欢的主题反复曝光；
- 身体、动作、居家等实用内容覆盖不足；
- 家长需要介入并替孩子规划；
- 产品已有的学习记录和复习能力无法充分发挥；
- 分类数量增加后，排在后面的主题长期得不到使用。

默认学习应该由系统承担基本覆盖责任，孩子只需要决定“现在要不要开始”。

### 4. 分类对家长和自由探索仍然有价值

分类本身不是问题。分类仍适合：

- 帮助家长理解产品包含哪些内容；
- 让孩子主动寻找喜欢的动物、颜色或车辆；
- 支持自由点读和反复播放；
- 组织和维护完整词库；
- 承载未来新增主题。

因此，本需求不是删除分类，而是将分类从“默认学习的必经入口”调整为“自由探索入口”。

---

## 二、用户与产品定位依据

### 1. 用户特征

HopEnglish 的核心用户具有以下特点：

- **非识字或初识字：** 不能依赖文字导航；
- **形象思维：** 更容易理解具体图片和动作反馈；
- **注意力短：** 需要尽快到达可玩、可听的内容；
- **工作记忆有限：** 同一页面上的主要决策应尽量少；
- **喜欢重复：** 会反复触发喜欢的声音和动画；
- **兴趣驱动明显：** 容易长期停留在单一偏好主题；
- **依赖稳定因果：** 相同动作应持续产生可预测结果。

### 2. 产品定位

HopEnglish 的定位是沉浸式、直觉式的幼儿英语启蒙工具，而不是要求儿童主动规划学习的课程目录。

与定位一致的首页应做到：

- 一个页面只有一个最主要的儿童任务；
- 不依赖教程或文字解释；
- 打开后尽快进入声音与图片反馈；
- 默认路径帮助孩子获得相对均衡的内容覆盖；
- 同时保留兴趣驱动的自由探索空间。

---

## 三、关于分类的产品论证

### 1. 保留分类作为首页主入口的理由

保留分类具有以下价值：

- 孩子可以主动选择喜欢的主题；
- 分类图标能提供一定的内容预期；
- 重复进入喜欢的主题符合“重复即学习”；
- 家长能够直观看到产品内容范围；
- 完整词库更容易扩充和维护；
- 自由探索更接近孩子使用声音玩具的方式。

这些理由说明分类有价值，但不能证明分类必须成为每次学习前的必选步骤。

### 2. 首页去分类的理由

首页去分类可以：

- 减少儿童开始学习前的决策负担；
- 将到达第一个单词的主路径缩短为一次点击；
- 让首页从内容目录转变为学习起点；
- 由系统负责主题轮换和基本覆盖；
- 减少孩子长期只选择单一主题的情况；
- 更好地发挥现有学习、测验和复习能力；
- 强化“点一下就开始”的产品直觉。

### 3. 为什么不完全删除分类

完全删除分类会损害：

- 儿童寻找喜欢主题的能力；
- 家长理解内容构成的能力；
- 自由点读和重复探索；
- 完整词库的组织与扩展。

因此，分类应继续存在于 Word Library，而不再成为儿童默认学习的门槛。

---

## 四、最终产品决策

儿童首页移除全部分类卡片，改为一个明确的一键学习入口。

产品形成两条互补路径：

1. **默认学习路径：** 点击 `Let's Play`，系统自动安排下一节现有分类课程。
2. **自由探索路径：** 进入 Word Library，继续按现有分类浏览和点读。

产品原则为：

> 分类服务于探索，系统服务于学习；儿童可以选择主题，但不必每次先选择主题。

本次“首页去分类”仅指不再要求儿童在首页主动选择分类。现有分类、分类中的单词以及学习页内的主题表达继续保留。

---

## 五、产品目标

### 1. 核心目标

- 将“打开 App 到看到第一个单词”缩短为一次主要点击；
- 消除儿童在首页理解和选择分类的负担；
- 让系统承担主题轮换责任，减少长期偏科；
- 保留儿童主动探索喜欢主题的能力；
- 使首页与“直觉、即时、零解释”的产品定位一致；
- 让默认学习路径和现有课程闭环保持一致。

### 2. 非目标

本次不调整：

- 分类数量、名称、顺序和内容；
- 现有单词的增加、删除、命名或归类；
- 单词图片、分类图片和音频资源；
- 每课 5/6/8 词设置；
- 单词学习、听音选图、复习和庆祝机制；
- Word Library 的分类浏览方式；
- 学习页中的分类标题；
- 现有词库的数据设计。

本次不引入跨分类的场景化课程。默认课程仍使用现有单分类结构，只是分类由系统安排，不再由儿童在首页选择。

## 六、新首页信息架构

首页从“内容目录”调整为“开始学习页面”。

```text
┌──────────────────────────────┐
│ HopEnglish        词库  设置 │
│                              │
│                              │
│         品牌图标/角色         │
│                              │
│       ┌──────────────┐       │
│       │ ▶  Let's Play │       │
│       └──────────────┘       │
│                              │
│       Tap, listen & play     │
│                              │
└──────────────────────────────┘
```

### 1. 页面层级

首页包含三个层级：

1. **主要儿童入口：** `Let's Play`；
2. **品牌视觉：** 现有 App 图标或品牌角色；
3. **次要入口：** Word Library 和 Settings。

所有分类卡片从首页移除。

### 2. 首页不展示

- 分类卡片和分类网格；
- 分类名称或分类数量；
- 推荐分类轮播；
- 已学词数量；
- 学习进度数字；
- 连续学习天数；
- 课程锁、等级或失败状态；
- 多个并列的开始按钮。

---

## 七、`Let's Play` 主入口需求

### 1. 视觉要求

- `Let's Play` 是首页尺寸最大、对比最强的可点击元素；
- 使用明显的播放图标，让孩子不依赖文字也能理解；
- 点击区域足够大，允许低龄儿童不精确点按；
- 使用圆角、高对比色和适度阴影，与现有儿童视觉风格一致；
- 品牌视觉应将注意力引导向主按钮，而不是形成新的内容选择。

### 2. 交互要求

- 点击后立即产生按压、缩放或高亮反馈；
- 同一次加载过程中不可重复触发；
- 课程准备完成后直接进入第一个单词；
- 不出现“请选择主题”“是否继续”等确认步骤；
- 不增加首次使用教程或说明弹窗。

### 3. 文案要求

- 可见名称固定使用 `Let's Play`；
- 不根据状态切换为 Start、Continue、Review 等不同文案；
- 保持相同入口产生相同结果：点击后开始或继续系统安排的学习；
- 文字是视觉辅助，播放图标和按钮形态承担主要可理解性。

---

## 八、自动安排现有分类课程

### 1. 基本原则

系统沿用现有分类课程，只把分类选择权从儿童首页转交给默认学习路径。

- 第一次使用时，从现有分类列表的第一个分类开始；
- 每次课程只使用一个分类；
- 一节课程仍学习当前设置的 5/6/8 个词；
- 完成当前课程后，下次安排分类列表中的下一个分类；
- 完成最后一个分类后，从第一个分类重新开始；
- 分类轮换对儿童不可见，不要求儿童理解轮换规则。

### 2. 未完成课程

如果孩子在学习或测验过程中退出：

- 当前分类不推进；
- 下次点击 `Let's Play` 时仍进入当前分类；
- 不因为切后台、返回首页或关闭 App 而自动切换主题；
- 只有完成学习和全部测验、进入庆祝页后，才视为完成本节。

本次不要求恢复到退出前完全相同的单词位置，但必须保持当前主题不变，避免孩子返回后突然进入无关内容。

### 3. 已完成课程

课程完成并进入庆祝页后：

- 系统将下一次默认课程推进到后续分类；
- 点击 `Home` 返回首页后，下次 `Let's Play` 进入后续分类；
- 点击 `More` 直接进入后续分类课程；
- 最后一个分类完成后，后续课程回到第一个分类。

### 4. 自由探索

在 Word Library 中：

- 所有现有分类继续展示；
- 孩子和家长可以主动选择分类；
- 可以点读任意单词并重复播放；
- 自由探索不改变首页默认课程的分类轮换位置。

这样可以避免孩子为了寻找喜欢的单词而打乱系统安排，同时保留完整探索能力。

## 九、完整用户流程

### 1. 默认学习

```text
打开 App
  ↓
点击 Let's Play
  ↓
系统安排当前分类
  ↓
学习 5/6/8 个词
  ↓
听音选图
  ↓
庆祝页
  ├─ More → 下一个分类课程
  └─ Home → 首页
```

### 2. 中途退出

```text
学习或测验中
  ↓
返回首页/关闭 App
  ↓
分类不推进
  ↓
再次点击 Let's Play
  ↓
继续当前分类
```

### 3. 自由探索

```text
首页
  ↓
Word Library
  ↓
选择分类
  ↓
自由点读单词
  ↓
返回首页
  ↓
默认课程安排不变
```

## 十、关键页面状态

### 1. 首次使用

- 首页直接显示 `Let's Play`；
- 点击后进入第一节现有分类课程；
- 不展示分类说明或产品教程；
- 不要求家长先做课程配置。

### 2. 返回用户

- 首页结构与首次使用保持一致；
- 点击后进入当前未完成分类或下一个待学习分类；
- 不要求孩子理解“继续学习”的文字含义；
- 不在首页暴露内部课程轮换。

### 3. 加载中

- 点击主按钮后立即给予视觉反馈；
- 主按钮暂时不可重复点击；
- 使用轻量、愉悦的加载表现；
- 不跳转到空白页；
- Word Library 和 Settings 在课程启动过程中不应造成重复导航。

### 4. 加载失败

- 保留在首页；
- 恢复主按钮的可点击状态；
- 显示简短、温和的 `Please try again`；
- 不显示技术错误、错误码或失败惩罚；
- 再次点击可以重新尝试。

---

## 十一、为什么不采用其他方案

### 1. 不采用“只保留少量分类”

即使把首页从 12 类减少到 6 或 8 类，孩子仍然需要在开始学习前做主题选择。“多少类合适”无法解决分类本身是额外前置任务的问题。

减少分类还会带来新的争议：

- 哪些主题应该保留；
- 被隐藏主题中的词如何处理；
- 兴趣主题与生活主题如何取舍；
- 是否需要重新归类单词。

这些问题超出本次首页简化目标。

### 2. 不采用“全词库随机”

全词库随机可能产生缺乏联系的组合，例如同时出现食物、职业、颜色和动物，导致：

- 一节课缺少稳定主题；
- 儿童难以形成预期；
- 听音选图的干扰项质量下降；
- 当前按分类组织的学习与进度逻辑被破坏。

本次继续使用现有单分类课程，只改变分类的选择者。

### 3. 不采用“删除分类和分类词”

删除分类会损害自由探索、家长理解和完整词库价值，也会把首页信息架构调整扩大为内容工程。本次没有证据证明现有分类或词应该被删除。

### 4. 本次不采用场景化课程

场景化课程可能具有长期教育价值，但需要重新设计：

- 跨分类取词；
- 课程主题和顺序；
- 学习进度归属；
- 测验干扰项；
- 内容配置方式。

本次先独立验证“儿童是否不需要主动选择分类”，避免把首页改版和课程体系重构混在同一期需求中。

---

## 十二、风险与应对

| 风险 | 影响 | 应对方式 |
|---|---|---|
| 孩子失去主动选择喜欢主题的能力 | 兴趣和重复动机可能下降 | 保留 Word Library 分类探索 |
| 自动进入不喜欢的主题 | 孩子可能提前退出 | 保持单课短时长，完成后轮换 |
| 家长误以为分类内容被删除 | 对产品内容完整度产生疑虑 | Word Library 完整保留分类和单词 |
| 首页元素减少后显得空 | 产品吸引力下降 | 强化品牌视觉、主按钮尺寸和即时动效 |
| 孩子误触 Word Library 或设置 | 偏离默认学习路径 | 降低次级入口视觉权重 |
| 隐藏分类后内容不可预测 | 稳定感下降 | 一节课内部保持单一分类，学习页继续显示主题 |
| 自动轮换导致当前兴趣被打断 | 主动性下降 | 孩子仍可通过 Word Library 随时寻找喜欢主题 |

## 十三、验证指标

### 1. 核心行为指标

- 从首页进入学习页的成功率；
- 打开 App 到第一个单词出现的时间；
- 首页停留时间；
- 首页直接退出率；
- 课程开始率；
- 课程完成率；
- 点击 `More` 继续下一课的比例；
- 一段周期内被学习过的分类数量；
- Word Library 的进入率和点读使用率。

### 2. 预期变化

- 首页停留时间下降；
- 从首页直接开始课程的比例上升；
- 到达第一个单词的操作步骤减少；
- 不同分类的长期覆盖更加均匀；
- 课程完成率不因失去首页选题而明显下降；
- Word Library 使用率可以下降，但不应完全消失。

### 3. 保护性指标

以下情况不应因首页去分类而明显恶化：

- 进入课程后短时间退出的比例；
- 单词主动重复播放次数；
- 听音选图完成率；
- 庆祝页后的继续学习率；
- Word Library 中主动探索行为。

## 十四、用户观察项目

分别邀请 2–3 岁和 4–5 岁儿童，在家长陪同但不主动指导的情况下观察：

### 儿童观察

- 是否能够在没有说明的情况下发现并点击主按钮；
- 是否会寻找原来的分类卡片；
- 点击后能否理解已经开始学习；
- 自动进入主题后是否愿意继续；
- 遇到不喜欢的主题时会退出、继续还是寻找词库；
- 想找动物或车辆时是否能够表达探索意图；
- 主按钮是否会被反复误触。

### 家长观察

- 是否理解首页负责默认学习、Word Library 负责自由探索；
- 是否误以为分类或内容被删除；
- 是否认为一键开始减少了陪伴操作成本；
- 是否担心孩子失去选题自由；
- 是否能够找到每课词数设置和完整词库；
- 是否认可系统自动轮换主题。

## 十五、产品验收标准

- 儿童首页不出现任何分类卡片或分类选择流程；
- 首页只有一个视觉上明确的主要学习入口；
- 打开 App 后一次主要点击即可进入现有学习流程；
- 主按钮不依赖文字说明也能被儿童理解；
- 中途退出不会推进到下一个分类；
- 完成课程后能够安排后续分类；
- `More` 可以直接进入后续课程；
- Word Library 中现有分类和单词完整保留；
- 自由点读不改变默认课程轮换；
- 学习、测验、庆祝和每课词数设置的产品行为不变；
- 不引入分类和单词内容调整；
- 不引入场景化课程或跨分类课程；
- 不需要儿童理解系统内部分类轮换规则。
