# 内容资源生产与验收

字段、路径和稳定 ID 的唯一来源为 [内容 Schema](../data_schema.md)。本指南处理修改词表、生成图片/语音与采用资源的工作顺序。

## 1. 变更前

1. 定位 categoryId、wordId、含义与当前资源引用；重名词必须使用完整学习项身份。
2. 核对是否只换素材、变更词义，还是迁移 ID/分类。后两者会影响历史进度，需要明确业务依据。
3. 查对应提示词覆盖、当前工具参数和输出路径；先确定授权生成范围和是否会覆盖正式文件。

`nameZh` 用来辅助内容含义，不会自动进入儿童学习画面。词条重名不意味着素材与进度都共享。

## 2. 图片工具的真实流程

工具目录 `scripts/dreamina-word-generator/`，模块为 ESM，依赖按 package-lock 安装。当前输出 512×512 透明 PNG，任务键 `categoryId/wordId`，最终名 `{category}_{word}.png`。

```bash
# 在工具目录中执行；生成会调用外部服务并消耗额度，需在任务授权范围内使用。
npm run generate -- --words=nature/moon,actions/swim --candidate
npm run generate -- --words=nature/moon,actions/swim --accept-candidates
```

- 候选、原图、状态和 submit_id 在 `.state/`；中断后优先复用远端任务或结果，不重置不明状态后重新付费。
- `--force` 会重提任务；仅在确定要重生成时使用，不能当作普通重试参数。
- 分类图标使用 `--category-icons` 分支，候选目录与单词图不同，采用后是否回写词表要核对实际参数。
- `--apply-images` 会更新词表；脚本中的错误提示不一定代表 parser 真支持对应选项，使用前回查 `parseArgs`。

## 3. TTS 工具的真实流程

工具目录 `scripts/tts-generator/`，模块为 CommonJS，当前依赖按 pnpm-lock 安装。现有脚本支持按 id/name 选首个匹配，生成 Normal/Slow WAV。

- 当前没有 category/wordKey 筛选、候选模式、远端任务恢复和试听采用命令，不能照搬图片工具的能力。
- 默认输出直接指向正式音频目录；需要先试听时用实际支持的 `--output` 指向临时目录，人工核对后再采用。
- `extractWords` 只保留 id/name，输出按 id 命名；跨分类相同 ID 的选择有歧义，重复条目可共享输出。强制全量生成可能重复请求同一目标，先限定范围并核对共享关系。
- 密钥由环境传入，避免写进仓库、调用示例的真实参数或日志；不因为缺凭据就改用另一项外部服务。

## 4. 验收维度

| 维度 | 验收方法 | 不能替代 |
|---|---|---|
| 结构与引用 | 字段类型、ID 唯一、完整路径、Normal/Slow 成对、pubspec 声明 | 不证明图意和音频内容 |
| 图片技术质量 | 尺寸、透明背景、边缘残色、主体留白、目标背景下预览 | 文件头合法不等于无抠图问题 |
| 图片语义 | 单一易识别主体、词义与分类一致、适合幼儿 | 生成器成功状态不等于语义正确 |
| 声音 | 发音、重音、语速、音量、静音截断、Normal/Slow 一致性 | 文件存在不等于可听或正确 |
| 运行效果 | 学习/测验/词库/庆祝显示和播放 | 源码图片预览不等于最终布局 |

先以代表样例验证参数，再执行授权批量任务；替换少量素材直接检查受影响画面与声音，不为此建立大型资产平台。

## 5. 采用后的收口

- 保留稳定 ID；词表相对文件名与模型 getter 匹配，不加入重复的 `assets/` 前缀。
- 执行 `flutter test --no-pub test/resource_validation_test.dart`，内容快照变化说明依据并同步测试中的数量约束。
- 检查 Git 差异只包含授权素材与必要配置，不把 `.state/`、候选原图、密钥和工具缓存提交进应用包。
- 在交付中明确完成的是生成、采用、完整性验证还是人工语义验收，不合并成一句“素材已完成”。
